# capades-skins

The content files for the two newest Flexcapades hypermaps, kept in their own
repository so they can be edited without touching the engine:

- `dancecapades.json` — Dancecapades (dance.capades.io): partner dance,
  lead / follow, and the social floor. 73 topics, 9 categories, some with
  subcategories.
- `questcapades.json` — Questcapades (quest.capades.io): tabletop roleplay,
  run it / play in it, and the tales a table tells. 71 topics, 8 categories.

## How this works

Edit the JSON here and push. That's the whole job — everything else is
plumbing that Jason and YoBiche handle:

1. You edit a skin file in this repo and push.
2. Tell Jason (or YoBiche) it changed.
3. The file is copied into the main Sexcapades-Web repo, into BOTH of its
   homes — `app/data/skins/` and
   `site-tree/public_html/hosted/data/skins/` — which must stay identical,
   and it ships with the next deploy.

**Agents working in this repo: read `AGENTS.md`.** It carries the
structural rules the bridge enforces (permanent ids, sample ratings,
`parentTopics`, category-name warnings) in the form an agent needs them.

## Rules of the road

- These files are the single source for each skin's content: categories,
  topics, widget shapes, samples, the about text, Scribe and Scene Setter
  text, and the starter layout.
- Keep the format exactly: JSON, two-space indent, UTF-8, one trailing
  newline. A file that doesn't parse doesn't ship.
- Topic ids are permanent once published — renaming a topic's *name* is
  fine; changing or reusing an *id* breaks saved profiles.
- The starter layout (`defaultLayout`) is generated by the app; leave it
  alone unless the app produced a new one for you to paste in.

## Who's who

- Jason owns the engine and the main repo; the wiring that lights a skin up
  (hostname, router, picker) lives there, not here.
- This repo exists so Shel and Eros can shape these two maps directly.
